# PEPEPOW Core v2.9.0.6 — Integration Provenance

## Merged source

The v2.9.0.6 Optional candidate was merged into [MattF42/PePe-core PR #41](https://github.com/MattF42/PePe-core/pull/41), producing official master commit `1522845bcd6c75ab5086f96d2a9977eecef74849`.

The integration combined:
- Original Masternode/Qt/wallet UI fixes from fork PRs #4–#10.
- Linux packaging and Qt refinements from fork PR #15.
- Wallet persistence reporting (A), Qt consolidation shutdown (B) and Recovery orphan guard (C) from fork PR #18.
- Three-platform candidate build support from fork PR #19, consolidated through fork PR #20.

The historical PRs are closed; earlier experimental branches are not final release sources.
